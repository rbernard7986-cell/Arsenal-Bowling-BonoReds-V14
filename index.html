💾 Sauvegarde

Exportez régulièrement une copie complète de l’arsenal, du profil joueur, des parties et des informations d’entretien.

Utilisation recommandée

  1. Appuyez sur Exporter JSON.
  2. Sur iPhone, choisissez Enregistrer dans Fichiers dans la feuille de partage.
  3. Sur PC ou Android, le fichier est téléchargé automatiquement.
  4. Conservez la sauvegarde dans OneDrive, iCloud Drive ou un dossier sécurisé.

La réinitialisation efface uniquement les données locales de cette application. Elle ne supprime pas les fichiers JSON déjà exportés.
